# swop-website

Marketing site and blog at **swopme.co**.

## Where this fits

The public front door. It is not a client of the platform in the way the app is —
it markets Swop rather than operating it — but it links into product surfaces and
shares the brand domain.

For the cross-repo map, see **[swop-app-backend/docs/ECOSYSTEM.md](https://github.com/Travisswop/swop-app-backend/blob/main/docs/ECOSYSTEM.md)**.

## Deployment

**A push to `main` is a production deploy** (Vercel). There is no staging gate.

## A domain note

`swop.tech` is squatted and is **not** Swop's domain. Never link to it. Swop's
domains are `swopme.co` and `swopme.app`.
